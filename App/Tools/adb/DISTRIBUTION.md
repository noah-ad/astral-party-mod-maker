# Android SDK Platform Tools

The full portable package includes adb.exe, AdbWinApi.dll, AdbWinUsbApi.dll,
libwinpthread-1.dll, source.properties and NOTICE.txt from Google's official
platform-tools Windows archive. Version: 37.0.1.

Upstream: https://developer.android.com/tools/releases/platform-tools
Archive: https://dl.google.com/android/repository/platform-tools-latest-windows.zip

See NOTICE.txt for the bundled components' licenses. These tools are used only
for USB device access, file backup, installation and SHA256 verification. The
application does not enable root, change system permissions, or change proxies.
