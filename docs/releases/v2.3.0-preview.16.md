# v2.3.0-preview.16

本次公开更新合并 preview.13 至 preview.16 的本地改进，仍作为预发行版；稳定版保持 v2.2.1。

## 下载前确认

附件 `AstralPartyModMaker-v2.3.0-preview.16-win64-core.zip` 是 **Windows 64 位核心包**，不是完整视频包。解压后双击顶层 `吉星Mod制作器-v2.3.0-preview.16-核心版.exe`，并保留同目录 `data` 文件夹。包内附带 .NET 8，无需另外安装运行环境。

**核心包不含 FFmpeg、Python 和 CriCodecs，不能转换视频 / GIF，也不能生成依赖这些组件的动态预览。** 静态资源制作、索引、分类、导出和还原仍可使用。视频转换运行时的再分发条件尚未确认，因此本次不上传完整视频运行时。源码包含以下动态功能，完整视频版目前只用于本地构建。

## 主要更新

- **独立动态文件**：立绘、手牌、事件改用各自的 `JixVideos/JixVideo_<贴图名>.usm`，不再读取或替换 `VHandCard_13021002`。复用原生播放器 `SetFile`，支持多个目标共存。仍需修改热更新程序集，不是纯贴图替换。
- **独立文件还原**：首次备份、哈希校验、分阶段写入和失败回滚；还原恢复原程序集并移除本工具新增的视频。旧借槽补丁需先还原，不能直接叠加。
- **技能大立绘 / 特写**：识别真正的 `VSkill_Hero...` / `VSkill_Monster...` 原生视频，归入对应角色与皮肤。`Talent*` 图集明确标为 Q 版动作。原生技能视频替换不修改游戏 DLL。
- **技能时长提示**：详情和取景窗口显示原始时长、帧数，长视频提示预计截断秒数。转换保持原技能尺寸、帧率及帧数，短片停留在末帧，不延长技能流程。
- **直接还原入口**：资源详情、右键菜单及工具 / 维护可以还原，不需要先导入视频。资源或备份发生变化时拒绝覆盖。
- **索引与记录修正**：修复 Windows 路径大小写导致的大量误重扫；原生技能视频从 catalog 加入索引、按需读取；修正负数 PathId 的已修改状态匹配。
- **清楚区分版本**：EXE、文件夹、窗口标题和包信息显示版本号及核心版 / 完整视频版，继续采用 EXE + data 布局。
- **启动方式**：通过 Steam 启动游戏，不修改系统代理、证书或联网代码。

## 独立视频的使用范围

完整视频版仍支持拖入视频 / GIF、按比例拖动裁剪和手动去绿幕。独立视频 ZIP 包含当前全部绑定所需的程序集包、现有 `__info` 和独立 USM，保持相对路径，只用于同平台、同游戏版本的 `AssetBundles` 根目录，不会把 PC 资源转成 Android 资源。

文件缺失或在 `JixVideos` 内存在 `disabled` 文件时，下一次绘制会保留静态映射。这不等于能自动处理所有原生解码错误。完整还原请使用工具的还原按钮，单独解压恢复 ZIP 不能删除新增文件。

## 验证与限制

- 369 项回归通过，涵盖裁剪、透明通道、卡牌绑定、过期回调保护、失败回滚和 100% / 模拟 150% 界面检查。
- Windows 真实资源副本通过立绘、手牌、事件共存，重复替换、导出与逐字节还原测试。
- 真实程序集检查中，除六个目标入口外的 65,329 个原有方法保持不变；没有新增运行时类型、外部程序集依赖或启动初始化代码。
- 原生 CRI 库在隔离进程中直接读取独立 USM 后到达 `Ready`；这不是游戏内播放验证。
- **独立方案的实际游戏内启动 / 播放和 Android 兼容性尚未完成验证，不宣称已经修复此前所有启动问题。** 首次建议只替换一个目标，并保留备份。

不包含游戏资源、热更新 DLL、用户 Mod、个人日志或本地视频转换二进制。
