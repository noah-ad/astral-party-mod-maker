# v2.3.0

本版修正 preview.16 公开核心包无法启用视频转换的问题，并更新 GitHub 最新发行版入口。

## 下载与启动

下载附件 **`AstralPartyModMaker-v2.3.0-win64.zip`**，完整解压后双击
`吉星Mod制作器-v2.3.0-标准版.exe`。保留旁边的 `data` 文件夹，无需另外安装 .NET。

**标准版可以使用视频 / GIF 动态功能。** 首次拖入视频时，点击“下载并启用”，
程序从 FFmpeg 构建发布者、Python 官网和 PyPI 下载约 117 MB 的固定版本组件，
校验 SHA256 后自动安装，再继续处理刚选的视频。无需手动安装 Python、执行命令或配置路径。
也可通过“工具 / 维护 → 启用视频组件”提前安装；安装后在同一电脑同一用户下可离线转换。

此 ZIP 不是预装全部组件的离线包，首次启用需要访问组件原站。下载中断可重试，
已校验的完整下载会复用。“工具 / 维护”提供检查 / 修复入口。

## 本版改动

- 接入立绘、手牌、事件、技能特写和 Q 版动作的一键组件启用。
- 补齐标准包中的原生技能视频检查脚本 `inspect_movie.py`。
- 固定组件版本、大小和 SHA256；阻止不安全解压路径，失败不激活半成品。
- 支持取消、超时重试、下载缓存、安装目录原子切换和 Windows 短暂文件占用重试。
- 保持 EXE + data 结构，版本号和窗口标题更新为 v2.3.0 标准版。
- 默认构建可公开使用的标准包，不再把不能启用转换功能的核心包作为新版本下载。
- 本次不修改游戏资源、系统代理、证书或现有视频补丁逻辑。

包含 preview.13 至 preview.16 的角色 / 皮肤分类、选择导出、独立 USM、原生技能特写、
时长提示、备份和直接还原功能。功能细节见 [README](https://github.com/noah-ad/astral-party-mod-maker/blob/v2.3.0/README.md)。

## 验证和限制

发行前验证干净标准包从原站下载组件、视频转换、透明 USM 封装及动画预览，
并执行回归测试和 EXE + data 启动检查。组件不通过仓库二次分发，
来源与校验值见 [组件说明](https://github.com/noah-ad/astral-party-mod-maker/blob/v2.3.0/App/Tools/video/DEPENDENCIES.md)。

**独立动态立绘 / 手牌 / 事件仍为实验功能**，仍需修改热更新程序集；
实际游戏内启动 / 播放和 Android 兼容性尚未全面验证。发布为最新版本不等于已解决所有启动问题。
原生技能特写只替换自身视频包，不修改游戏 DLL。首次使用请保留备份，避免叠加旧补丁。

不包含游戏资源、热更新 DLL、用户 Mod、个人日志或第三方视频转换二进制。
