# v2.3.1

## 怪兽立绘补齐

- 识别 `UT_Monster_Card_*`、`UT_Monster_Bust_*` 以及对应头像等角色贴图命名，不依赖固定怪兽编号列表。包括 `UT_Monster_Card_1071`。
- 怪兽卡面、半身图归入“角色 / 皮肤 / 怪物 → 怪兽”，不再落入默认隐藏的“其它贴图”。
- 保留怪兽编号、皮肤、Max 和和谐版本信息；卡片显示编号，便于区分和搜索。
- 加载已有完整索引时重新计算分类和计数；轻量索引同步重建角色引用。分类变化无需重新扫描未改动的资源包。
- 保留静态图片预览、替换和导出流程，不扩展怪兽动态替换，不修改游戏热更新 DLL、资源或联网设置。

## 本地启动

完整解压 ZIP 后双击 `吉星Mod制作器-v2.3.1-标准版.exe`，并保留同目录 `data`。
静态怪兽立绘不需要视频转换组件。旧索引中的资源会自动重新分类；若游戏刚更新，工具会对变化的包执行增量扫描。

v2.3.1 为本地构建；以上改动已包含在公开发行版 [v2.3.2](v2.3.2.md)。
