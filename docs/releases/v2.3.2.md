# v2.3.2

修复高分辨率、高 DPI 缩放下部分选项和按钮显示不全的问题，合并 v2.3.1 的怪兽立绘补齐。

## 下载与启动

下载附件 `AstralPartyModMaker-v2.3.2-win64.zip`，完整解压后双击
`吉星Mod制作器-v2.3.2-标准版.exe`。保留旁边的 `data` 文件夹，包内已包含 .NET 运行环境。

视频 / GIF 功能继续提供一键组件安装。首次拖入视频时点击“下载并启用”，或在
“工具 / 维护 → 启用视频组件”提前准备；本机已启用的组件可继续复用。

## 界面修复

- 统一 96 DPI 布局基准，修复字体已放大、部分面板却被固定像素尺寸重置的问题。
- 资源浏览的类型、搜索和刷新按钮按可用宽度分行，标题与筛选项互不遮挡。
- 作品与维护页按文字实际尺寸调整按钮，操作区自动换行；作品条目随窗口宽度重新排版。
- 导出选择窗口的搜索、时间范围、全选和清空按钮自动换行，底部操作区及说明按内容调整高度；列表列宽随窗口与字体调整。
- 图片裁切工具栏可换行，视频 / 技能替换及组件窗口使用统一 DPI 基准。
- 资源详情保留纵向滚动；较矮窗口优先给分类树留空间，低频资源选项可完整换行显示。
- 打开窗口及切换不同 DPI 屏幕后，窗口边界适配当前工作区。

## 怪兽立绘

- 补齐 `UT_Monster_Card_*`、`UT_Monster_Bust_*` 等命名的识别，包括 `UT_Monster_Card_1071`。
- 归入“角色 / 皮肤 / 怪物 → 怪兽”，显示怪兽编号，保留皮肤和和谐版本。
- 旧索引自动刷新分类，未变化的资源包无需因本次分类调整重新扫描。

## 验证与范围

布局检查覆盖 100%、125%、150%、200%、250% 模拟 DPI，并限制窗口到屏幕可用大小，检查按钮边界、文字、换行和导出筛选交互。150%、250% 另有截图检查。仍需以实际多显示器环境的结果为准。

沿用标准版的视频转换组件启用、独立动态资源、原生技能特写、导出与还原功能。
独立动态立绘 / 手牌 / 事件的游戏内及 Android 兼容性限制见 README；本次更新不改动其补丁方案。

发行包不含游戏资源、用户 Mod 或个人日志。
