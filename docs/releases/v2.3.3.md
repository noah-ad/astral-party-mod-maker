# v2.3.3

修复“导出已改 Bundle ZIP”混选基础资源与热更新缓存时失败的问题。

## 导出修复

- 一次选择、一次导出；混合来源自动生成 `文件名-基础资源.zip` 和 `文件名-热更新缓存.zip`。
- 基础资源 ZIP 覆盖到原基础资源目录，热更新缓存 ZIP 覆盖到 `AssetBundles` 根目录。
- 每个 ZIP 仍只保存原始相对路径；不增加 `current`、`original`、工程清单或其它套层。热更 `__data` 自动配套导出 `__info`。
- 单一来源仍导出为保存窗口中选择的文件名。
- 导出前检查实际输出文件是否存在，确认后才替换。先完成全部压缩，再提交输出；后一个文件失败时恢复本轮已替换的压缩包。
- 压缩放到后台执行，导出期间仍可浏览界面；重复导出会被拦截，完成后可以关闭窗口。

## 本地启动

双击 `吉星Mod制作器-v2.3.3-标准版.exe`，保留同目录 `data`。视频组件沿用此前一键安装入口。

此版本为本地构建，公开发行版下载入口保持 v2.3.2。
