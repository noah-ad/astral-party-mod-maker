# v2.3.4

本地构建，尚未发布到 GitHub Releases。

## Mod 记录与资源识别

- 兼容旧 `.jixmod.json` 的大小写字段、数字字符串和空修改时间。同一资源包按稳定的资源名称关联，资源编号变化后不再漏掉原有记录。
- 保存记录时使用临时文件和原子替换，保留上次有效记录 `.jixmod.json.bak`。读取失败会显示提示并尝试备份，不再静默当作空作品集；损坏原文件也会保留。
- 对仍在索引中且有 `_原始备份` 的包，在后台逐项比较贴图原始数据及原生技能视频，恢复确认有差异但缺少记录的项目。旧标签与修改时间不变；无法知道时间的恢复记录仍标为时间未知。
- 不再用 RGBA32 格式推测 Mod。原始 RGBA32、ASTC 修改以及同包内未修改的相邻贴图分别判断。
- 资源卡片、详情和作品页区分“已修改”“备份一致”“有记录”“未核验”。已还原、已过期的记录保留，但不进入当前修改与默认导出候选。
- 结果按资源和备份的长度、修改时间缓存；普通重开复用核验结果。切换目录、刷新索引或关闭程序会取消旧任务，避免将旧结果写入另一个作品集。
- 本次修复不修改游戏资源、动态补丁或代理设置。继续包含 v2.3.3 的混合来源 ZIP 导出修复。

## 边界

“备份一致”只表示与该目录的首次备份一致，不代表通过了官方原版校验。缺少备份时保留旧修改记录，未记录的内容显示未核验，不假称原版。未能读取的包也保留原记录，不做猜测。

## 启动

完整解压 `吉星Mod制作器-v2.3.4-win64-标准版.zip`，双击顶层 `吉星Mod制作器-v2.3.4-标准版.exe`，保留旁边的 `data` 文件夹。打开原资源根目录后会读取原来的修改记录，并在后台核验备份。

## 验证

- 470 项回归检查、1660 项模拟 DPI 布局检查通过。
- 真实多贴图资源副本验证了缺失记录恢复、相邻未改贴图识别、缓存复用及还原后的导出过滤；源游戏资源逐字节不变。
- PC 与 B 服资源目录的现有备份核验均无读取失败，覆盖 RGBA32 原始内容与 ASTC 修改。
- 实际主窗口打开游戏目录后，旧记录、核验状态与导出候选一致；取消旧目录任务的界面检查通过。
- EXE + data 便携包通过版本、图标、中文空格路径、移动后启动及随包运行库检查。
