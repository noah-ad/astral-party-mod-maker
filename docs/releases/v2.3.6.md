# v2.3.6

Win64 完整视频版。下载 `AstralPartyModMaker-v2.3.6-win64-full.zip`，完整解压后双击顶层 `吉星Mod制作器-v2.3.6-完整视频版.exe`。

## 修复动态资源定位

- 修复 v2.3.5 只在用户 `LocalLow` 缓存中找程序集的问题。当前游戏 3.3.0 的对应包实际存在于 `AstralParty_CN_Data/com.unity.addressables/AssetBundles`，并非尚未下载。
- 根据当前 `settings.json` / catalog 的包名和哈希，直接检查用户目录、所选游戏安装目录的缓存位置。不按文件时间选旧包，不扫描全部资源。
- 安装目录的独立视频与程序集、备份、还原记录使用同一缓存根目录，播放器通过 `Application.dataPath` 读取。Android 和用户缓存模式保留 `persistentDataPath`，不硬编码本机路径。
- 界面、直接写入 API、动态预览状态和 ZIP 导出使用相同的位置判断。导出后显示 ZIP 应覆盖的缓存目录。
- 旧目录中仍有动态记录时，保留还原入口，先还原再替换新版，不会把旧 DLL 自动迁移覆盖到新版。两处同时有当前程序集、或同版本 catalog 内容冲突时明确停止写入。

## 保留功能

完整视频版随包包含 FFmpeg、Python、CriCodecs 与封装脚本，不需要首次重新下载。保持启动 EXE + data 的便携结构。保留手牌、事件卡、角色立绘的独立动态功能，以及此前的卡图导入、Mod 记录修复和直接覆盖 ZIP 导出。

自公开版 v2.3.2 升级，还包含以下修复：

- 基础资源和热更新缓存混选时，自动分别导出两个可直接覆盖的 ZIP。
- 旧 Mod 记录按稳定贴图名关联，兼容游戏更新后的资源编号变化；后台对比原始备份恢复缺失记录。
- 修改状态和导出范围统一核验，已还原或失效的旧记录不会误计为当前 Mod；保留历史信息和备份。

## 验证与组件

- 543 项回归检查、100% 至 250% 的 1,660 项模拟 DPI 布局检查通过。
- 当前 Windows 3.3.0 资源副本完成手牌、立绘、事件共存安装、直接 ZIP 导出和逐字节还原。
- 67,026 个非目标游戏方法保持不变，包括启动相关方法；不增加启动初始化器或播放器类型。
- 完整包在空用户组件缓存下完成视频转换、去绿幕预览及透明度 / 连续帧检查，没有下载。
- 完整包移到中文、空格目录且未安装系统 .NET 时可启动，使用随包运行时和视频组件。
- 第三方版本、原始分发包、校验值、许可与源码入口见 `data/Tools/video/DEPENDENCIES.md`。Release 中的 `.whl`、FFmpeg 源码和校验清单供核对来源，普通用户只需下载完整应用 ZIP。

本次不修改游戏启动、联网、系统代理或官方异画槽位。排查真实游戏资源仅只读，安装与还原验证在隔离副本中执行。文件校验、模拟播放器及封包回读测试不能代替真实游戏内播放验证，独立动态仍为实验功能。
