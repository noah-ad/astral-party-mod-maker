# 吉星Mod制作器-v2.4.2

下载 `吉星Mod制作器-v2.4.2.zip` 后完整解压，双击顶层的 `吉星Mod制作器-v2.4.2.exe`。启动文件与 `data/` 必须放在一起。Win64 运行时、FFmpeg、Python、CriCodecs 和 ADB 已随包提供，不需要另外下载组件。

## 海外服与图包

- “工具 → 检测海外服”可单独打开国际版。选中游戏安装目录、`com.unity.addressables` 或它下面的 `AssetBundles` 也能定位基础包。国服和海外服各自读取基础包、安装缓存与用户缓存，独立资源目录不会混入这些缓存。
- 图包按当前资源库的贴图名匹配，不依赖另一服的 Bundle 名或 PathID。海外服支持同名普通 / `_sfw` 对应资源；图包提供两张时分别应用。写入在后台执行，显示进度并区分未匹配与读取、写入失败。请先关闭游戏。
- 首次扫描只读取贴图元数据；后续扫描复用未变更的索引。资源库显示定位、扫描、读取缓存和匹配修改记录等阶段，扫描有实际包数和百分比。

## 界面与安卓

- 深色界面、即时中英文切换、高 DPI 和窄窗口布局。资源库切换页面后保留预览和滚动位置。装饰插画与骰子从本机游戏资源读取，发行包不包含游戏素材。
- 安卓贴图按设备当前 APK 与资源表重建。支持 USB 备份、写入后 SHA256 校验和还原；导出 ZIP 同样做回读校验。文件校验不等同于游戏内画面验证。
- 保留分来源的直接替换 ZIP、旧 Mod 识别和原有视频功能。独立动态立绘、手牌与事件卡仍是实验功能。

## 附件

- `吉星Mod制作器-v2.4.2.zip`：日常使用只需这个文件。
- `SHA256SUMS.txt`：核对完整包和第三方附件用。
- FFmpeg 源码归档及原版 CriCodecs wheel：第三方分发资料，不用单独安装。详见 [组件与授权说明](https://github.com/noah-ad/astral-party-mod-maker/blob/v2.4.2/App/Tools/video/DEPENDENCIES.md)。

验证覆盖 Win64 便携启动、100%～250% 缩放、真实海外服基础与缓存资源索引，以及复制到隔离目录的普通 / `_sfw` 图包替换和像素回读。
